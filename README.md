# 面接振り返りアナライザー

就活・転職の面接練習を録画した動画 (mp4 など) をブラウザにドロップするだけで、
**話し方・表情・回答内容**を自動で分析し、振り返りレポートを作るローカル Web アプリです。

動画は自分の PC の中で処理されます (OpenAI / Claude の API を使う設定にした場合のみ、音声や文字起こしが各社に送信されます)。

## できること

| 分析 | 内容 | 使う技術 |
|---|---|---|
| 文字起こし | 発言を時刻つきでテキスト化。「えー」「あのー」も残す | ローカル Whisper (faster-whisper) / OpenAI API から選択 |
| 話し方 | 話す速さ (字/分)、フィラーの回数と種類、2 秒以上の沈黙、声の大きさ・抑揚 | 音声信号処理 (numpy) |
| 表情・視線 | カメラ方向を見ている割合、笑顔の割合、頭の揺れ、瞬き | MediaPipe Face Landmarker |
| 回答内容の講評 | 質問ごとの良い点・改善点・回答例、総合スコア、次回までにやること | Claude API (任意) |

レポート画面では、文字起こしやグラフ、講評の時刻をクリックするとその場面から動画が再生されます。
結果は Markdown で保存できます。

## 必要なもの

- macOS / Linux / Windows (動作確認は macOS Apple Silicon)
- [uv](https://docs.astral.sh/uv/) (Python のバージョンとライブラリを自動で用意します)
- [ffmpeg](https://ffmpeg.org/)

```bash
# macOS (Homebrew)
brew install uv ffmpeg
```

## セットアップと起動

```bash
git clone <このリポジトリの URL>
cd Mensetu
cp .env.example .env   # API キーを使う場合は .env に記入 (任意)
uv run python -m app
```

ブラウザで http://127.0.0.1:8000 を開き、動画をドロップします。

初回は Whisper のモデル (large-v3-turbo で約 1.6GB) と MediaPipe の顔モデルを自動でダウンロードするため時間がかかります。

### API キー (任意)

| 環境変数 | 用途 | 未設定の場合 |
|---|---|---|
| `OPENAI_API_KEY` | 文字起こしを OpenAI API (whisper-1) で行う | ローカル Whisper のみ選べます |
| `ANTHROPIC_API_KEY` | 回答内容の AI 講評 (Claude) | 数値分析とルールベースのアドバイスのみ |

API キーは `.env` に書きます。`.env` は `.gitignore` 済みなのでコミットされません。
講評は既定で `claude-opus-5-5` を使います (`.env` の `CLAUDE_MODEL` / `CLAUDE_EFFORT` で変更可)。
講評リクエストには、安全分類で回答が断られたときに別モデルへ自動で切り替える Claude API のサーバー側フォールバック (`fallbacks: "default"`) を有効にしています。

### 処理時間の目安 (Apple M2 Pro, CPU)

| Whisper モデル | 1 分の動画あたり | 精度 |
|---|---|---|
| `small` | 約 15 秒 | 誤変換がやや多い |
| `large-v3-turbo` (既定) | 約 30 秒 | 高い |

映像解析は文字起こしと並行して実行されます。AI 講評は 1〜3 分ほどかかります。

## 使い方のコツ

- **自分の顔が正面から映る録画**を使ってください (オンライン面接の画面録画なら、自分のカメラ映像が大きく映るレイアウトに)。
- 面接官と自分の声を区別する機能 (話者分離) はありません。話速・フィラーの数値には面接官の発言も含まれます。AI 講評は文脈から質問と回答を判別します。
- 「応募先・職種」欄に面接の情報を書くと、AI 講評がその前提で評価します。
- 数値の閾値は経験的な目安です。照明・マイク・カメラ位置で値が変わるので、**同じ環境で撮った前回の自分と比べる**使い方がおすすめです。

## 指標の見方

| 指標 | 目安 |
|---|---|
| 話す速さ | 300 字/分前後が聞き取りやすい。340 超はやや早口、380 超は早口 |
| フィラー | 3 回/分未満が目標 |
| 沈黙 | 5 秒以上の沈黙は「少し考えさせてください」と一言添えると良い |
| 声の抑揚 | 声の高さの標準偏差 (半音)。1.8 未満は単調に聞こえやすい |
| 目線 | 頭の向きと黒目の位置から「カメラ方向を見ている」フレームの割合。60% 以上が目安 |
| 笑顔 | 口角の上がり具合が一定以上のフレームの割合 |

## 構成

```
app/
  main.py        FastAPI サーバー (API と画面の配信)
  pipeline.py    解析ジョブの実行・保存
  media.py       ffmpeg による音声抽出・フレーム抽出
  transcribe.py  文字起こし (ローカル Whisper / OpenAI)
  speech.py      話し方の分析
  vision.py      表情・視線の分析 (MediaPipe)
  review.py      Claude による講評
  static/        画面 (HTML / CSS / JavaScript, Chart.js)
data/            アップロードした動画と解析結果 (git 管理外)
models/          ダウンロードしたモデル (git 管理外)
```

## プライバシー

- アップロードした動画と結果は `data/jobs/` に保存されます。画面の「削除」ボタンで消せます。
- `data/` と `models/` は `.gitignore` 済みです。**面接動画をリポジトリにコミットしないよう注意してください。**
- サーバーは既定で `127.0.0.1` (自分の PC からのみアクセス可) で起動します。
